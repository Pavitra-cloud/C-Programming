PRISON ESCAPE SIMULATOR  (C + raylib)

WINDOWS (your college PC / VS Code):
  1. Install raylib from raylib.com (installer -> C:\raylib).
  2. Double-click build_and_run.bat   (or in VS Code press Ctrl+Shift+B, then run prison.exe)
  Keep menu.png next to the exe if you have it (optional - the game draws its own menu without it).

LINUX: ./prison_linux     (needs a desktop; highscore.dat is saved next to it)

CONTROLS: W A S D / arrows = move, LEFT SHIFT = sprint, mouse = buttons, ESC = back to menu.
